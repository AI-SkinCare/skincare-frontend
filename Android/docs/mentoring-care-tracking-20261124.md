# 11월 24일 멘토링 반영 결과

## 앱에서 달라진 점

| 녹취에서 나온 질문 | 반영한 동작 |
|---|---|
| 성분 이름을 보고 사용자가 무엇을 할 수 있나? (05~07분, 17~24분) | 추천 상세에서 기존 성분의 목적과 시간대별 루틴에 이어 세안·보습 등 분류별 생활 관리 예시를 보여준다. 예를 들어 여드름 분류 결과에 표시되는 자외선 차단 성분의 제품 용도는 자외선 차단으로 표기한다. 햇빛을 개인의 여드름 원인으로 추정하지 않는다. |
| 음식이나 환경도 관리에 참고할 수 있나? (07분, 37~38분) | 여드름과 주사는 각각 식사와 음료 온도에 관해 관찰해 볼 행동을 출처와 함께 제공한다. 그 밖의 생성된 결과는 일반 식생활 안내를 제공한다. 음식 알레르기 추정, 특정 식품군 배제, 개인별 환경 원인 추론은 제공하지 않는다. |
| 성분에 맞는 제품을 바로 확인할 수 있나? (약 41분) | 제조사 성분표를 확인한 얼굴 보습제와 SPF 30 제품 두 가지를 등록했다. 실제 추천 성분이 일치하고 입력된 회피 성분을 모두 대조할 수 있을 때만 제품명·일치 성분·공식 성분표를 보여준다. 확인 불가 또는 일치 제품 없음도 화면에 표시한다. 추천 보류 건에는 제품 카드를 표시하지 않는다. |
| 하루가 지나고 무엇이 달라졌나? (39~40분) | 홈의 **매일 피부 기록**에서 직접 느낀 편안함을 0~10점으로 남긴다. 사진 제출 없이 사용 제품도 기록할 수 있다. 날짜별 막대와 점수를 표시하며, 빠진 날이 있으면 실제 직전 기록의 날짜와 비교한다. 같은 날은 수정하고 개별 기록은 삭제할 수 있다. 기록과 제품 사용의 동시 변화만 보여준다. |
| 다른 사람이 옆에서 찍어도 되나? (11~16분, 31~32분) | 렌즈와 별도로 **정면 / 측면**을 고른다. 측면은 얼굴 전체와 한쪽 볼이 보이는 구도다. Android는 내장 ML Kit, iOS는 Vision으로 얼굴 수·크기·회전 각도를 확인한다. 사진의 피부 병변 경계를 검출하는 기능과는 구별한다. |

질환 분류 결과가 불확실하거나 추천 품질 검사를 통과하지 못하면 기존 보류 동작을 따른다. 식습관과 제품 예시는 앱에 포함된 자료로 구성한다. 새로운 안내를 위해 사진·설문을 외부 생성형 AI에 전송하지 않는다. 일일 기록은 이 기기의 서버·계정별로 보관하며 다른 기기와 동기화하지 않는다.

## 정면·측면 모델과 배포

정면 또는 각도 미입력 → 기존 Spring 분석 API → FastAPI `/infer/disease` → DenseNet121 S2. 측면 → 기기 내 방향 검사 → Spring의 `sideCaptureAvailable` 확인 → FastAPI `/infer/disease/side` → DINOv2. 이후 추천은 해당 모델이 낸 라벨·6종 점수와 설문을 기존 추천 API에 전달한다. 촬영 각도는 분석 설문에 별도 기록하며 과거 이력의 누락 값은 그대로 둔다.

팀 AI 저장소의 박성근님 분류기 브랜치에 게시된 가중치는 DenseNet121 S2다. 이번 통합 시험에는 기존 프로젝트 실험의 동결 DINOv2-small + 선형 분류기 `dinov2_linear_875acf74c4`를 사용했다. 팀원이 별도로 학습한 측면 체크포인트의 동일성은 확인되지 않았다. [팀 AI 분류기 이슈](https://github.com/AI-SkinCare/skincare-ai/issues/3)

측면 전용 모델은 FastAPI 환경변수 `SIDE_DINO_WEIGHTS`로 지정한다. 현재 로더는 프로젝트의 `dinov2_linear` 체크포인트 계약(가중치, 백본·분류기 설정, 6종 클래스 순서, RGB 정사각 리사이즈·ImageNet 정규화)을 사용한다. 다른 구조의 팀원 모델은 원래의 전처리와 헤드에 맞춰 어댑터를 확인해야 한다. 로딩 성공 시 `/health`의 `side_dino_loaded`가 켜진다. 연동 버전의 Spring이 이 값을 앱에 전달한다. 11월 24일 조회한 팀 Spring은 정면 AI의 가용성을 보고했고 측면 기능은 광고하지 않았다. 이 경우 앱은 측면 사진을 전송하기 전에 안내한다.

## 근거와 후속 검증

- 일상 관리와 식습관 문구는 학회 환자 자료와 WHO 일반 식사 지침을 사용했다. 적용 조건과 출처 링크는 각 카드에 표시한다. [여드름과 식사](https://www.aad.org/public/diseases/acne/causes/diet) · [주사 유발 요인](https://www.aad.org/public/diseases/rosacea/triggers/prevent) · [세계보건기구 식생활 자료](https://www.who.int/news-room/fact-sheets/detail/healthy-diet)
- 제품은 미국 제조사 공개 표기를 기준으로 확인했다. 국가·시점별 성분 변경을 고려해 실제 포장 확인을 안내한다. [얼굴 보습제](https://www.vanicream.com/product/vanicream-daily-facial-moisturizer) · [SPF 30 제품](https://www.vanicream.com/product/facial-moisturizer-with-spf)
- 녹취에서 제안한 조명별 촬영 비교, 의심 부위 크롭, 질환 추가와 장기 점수의 임상 타당성은 별도 검증이 필요하다. 특히 같은 환자의 정면·좌우 측면 사진과 정답을 확보해 촬영 실패율, 질환별 재현율, 정확도와 표본 수를 함께 비교해야 한다. 제품 사용과 증상의 인과관계, 멤버십·광고 기능은 이번 구현 범위 밖이다.
