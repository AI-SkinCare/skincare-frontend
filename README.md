# skincare-frontend

피부 질환 및 타입 맞춤 AI 서비스의 프론트엔드 저장소입니다.

## 역할
사용자가 서비스를 이용하는 화면(웹/앱 UI)을 담당합니다. 피부 사진·설문 입력, AI 진단 결과 및 맞춤 추천 결과를 사용자에게 보여주는 역할을 합니다.

## 주요 기능 (예정)
- 피부 사진 업로드 및 설문 기반 정보 입력 화면
- 백엔드 API를 통한 진단 결과 조회 및 화면 표시
- 사용자별 피부 타입·질환 맞춤 추천 결과 제공

## 기술 스택
- 미정 (Node.js 기반 .gitignore 적용)
